# 🛒 NexShop - Full Stack E-commerce Website (MERN Stack)

[![React](https://img.shields.io/badge/React-18.2.0-blue?logo=react)](https://reactjs.org/)
[![Node.js](https://img.shields.io/badge/Node.js-18.0.0-green?logo=node.js)](https://nodejs.org/)
[![MongoDB](https://img.shields.io/badge/MongoDB-6.0.6-brightgreen?logo=mongodb)](https://www.mongodb.com/)
[![Express](https://img.shields.io/badge/Express-4.18.2-lightgrey?logo=express)](https://expressjs.com/)

NexShop is a Full Stack E-commerce Website built with the MERN Stack (MongoDB, Express, React, Node.js). It supports user authentication, shopping cart, product collections, and order management.

---

## Features

### User Portal

- Register/Login as user
- Browse products & collections
- Add to cart and place orders
- View order history

### Admin Panel

- Manage products (Add/Edit/Delete)
- Manage orders
- Dashboard analytics

### Cart & Orders

- Add/remove products from cart
- Place orders using COD or other methods
- Track user orders

---

## Technologies Used

- **Frontend:** React.js, Tailwind CSS, HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** JWT

---

## Folder Structure

```

Client/ # React frontend
Server/ # Node.js + Express backend
Admin/ # Admin panel frontend

```

---

## How to Run

### Backend

```bash
cd Server
npm install
npm run server
```

### Frontend

```bash
cd Client
npm install
npm run dev
```

### Admin Panel

```bash
cd Admin
npm install
npm run dev
```
